# Resource_monitoring_application (Монитор ресурсов)

Виджет для отображения системных ресурсов и ресурсов, потребляемых самим приложением, разработанный на **Qt** для **Linux**. Предназначен для визуального контроля загрузки процессора, памяти, дисковых операций и потоков как всей системы, так и конкретного процесса (приложения).

---

## Внешний вид

В качестве референса используется макет, представленный на скриншоте:

![Скриншот интерфейса](resources/reference%20design.jpg)

На изображении представлен минималистичный интерфейс со следующими элементами:

- **Переключатель** – «Включить мониторинг» (чекбокс для активации/деактивации обновления)
- **Показатели системы**:
  - ЦП Система – загрузка центрального процессора в процентах (например, 1%)
  - Память Система – занятость оперативной памяти в процентах и абсолютное значение доступной памяти (например, 32% / 44234 МБ доступно)
  - Чтение / Запись – скорость дисковых операций в МБ/с
- **Показатели самого приложения (помечены как «СПО АСЦП»)**:
  - ЦП СПО АСЦП – загрузка ЦП текущим процессом (0%)
  - Память СПО АСЦП – объём оперативной памяти, занимаемый процессом (299 МБ)
  - Запущенных задач – количество активных задач внутри приложения (0)
  - Потоков СПО АСЦП – количество потоков, созданных приложением (29)

---

## Цель задания

Разработать полнофункциональный виджет, который:

- Отображает перечисленные выше метрики в реальном времени (с заданной периодичностью обновления).
- Позволяет пользователю включать и отключать мониторинг через чекбокс.
- Работает исключительно в среде **Linux**, получая данные через системные вызовы.
